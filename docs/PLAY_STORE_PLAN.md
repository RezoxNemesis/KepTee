# KebTee Play Store release plan

## Store identity
- App name: KebTee
- Tagline: Your Phone, Your Style.
- Short description draft: Personalize your screen with live wallpapers, themes and custom UI styles.
- Category candidate: Personalization
- Package: com.rezoxnemesis.kebtee
- Release approach: internal testing before any public release

## Listing assets to prepare
- 512 × 512 app icon
- 1024 × 500 feature graphic
- Screenshots from real running builds
- Public privacy policy URL before any data collection or sensitive permission use

## Release checklist
- [ ] Confirm app name and package availability
- [ ] Build and test signed Android App Bundle (.aab)
- [ ] Verify target API requirements in Play Console at release time
- [ ] Complete accurate Data safety answers
- [ ] Document every permission and its user-facing purpose
- [ ] Test on target Realme device and emulator
- [ ] Test wallpaper lifecycle, rotation, lock/unlock, battery and thermal impact
- [ ] Prepare content rating, listing text, screenshots and privacy policy
- [ ] Complete Play testing requirements and resolve policy findings

## Permission philosophy
Start with minimal permissions. The live wallpaper does not require notification access, accessibility access, or overlay permission.
